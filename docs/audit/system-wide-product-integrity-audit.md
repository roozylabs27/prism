# Prism — System-Wide Product Integrity & Production Readiness Audit

**Audited Repository:** `github.com/roozylabs27/prism` (`main` @ `0b7ea87` + Phase 4 security/control-plane hardening)  
**Assessment Verdict:** **Architectural Alpha / Early Staging — NOT Yet Production-Ready for Unattended Multi-Tenant Commercial Launch.** Core Go proxy/tenant/failover infrastructure has solid foundations and critical P0 gaps were closed in Phase 4, but systemic `user_id` vs `org_id` scoping, non-durable async audit/financial pipelines, missing `/v1/messages`, broken non-OpenAI provider adapters, missing approval workflows, incomplete frontend workflows, and zero E2E Playwright tests remain before production sign-off.

---

## Verification Evidence Legend

Every finding in this audit explicitly states its verification level:
- **Code Inspection:** Verified by reading current source files, migrations, workflows, and configs directly.
- **Automated Tests:** Verified via `go test` / Vitest unit & mock-backed handler tests.
- **Integration / E2E Tests:** Verified against real PostgreSQL, Redis, local Docker stack, or full in-process HTTP server chains.
- **Real Production Environment:** Not verified (no production cluster inspection performed).
- **Not Yet Verified:** Historical or operational behaviors that cannot be proven from local inspection alone.

## 2. Detailed Findings Across Audit Areas (A–H)

### Area A — Security & Tenant Isolation
1. **[P0 — Fixed in Phase 4] Gateway Key `WorkspaceID`/`ProjectID` Header Override (`internal/middleware/tenant.go:102-116`)**
   - *Impact:* Client-scoped `prism_sk_*` keys could pass spoofed `X-Prism-Workspace-ID`/`X-Prism-Project-ID` headers to attribute costs or escape quotas into another client workspace.
   - *Remediation (Applied):* Pinned key-level `WorkspaceID`/`ProjectID` identically to `OrgID`, returning `403 TENANT_SECURITY_ERROR` (`ErrCrossWorkspaceForbidden`/`ErrCrossProjectForbidden`). *Verified by automated unit & E2E tests.*
2. **[P0 — Fixed in Phase 4] Cross-Tenant `ai_audit_trails` Data Leak (`internal/repository/audit_trail.go:119-125, 192-195`)**
   - *Impact:* Any user querying `/api/audit-trail` could read `'user_admin'` and empty-user rows; empty `UserID` skipped scoping completely.
   - *Remediation (Applied):* Removed `OR user_id = 'user_admin' OR user_id = ''`, required non-empty `UserID` fail-closed, and wired `StartDate`/`EndDate` filters. *Verified by automated tests.*
3. **[P0 — Fixed in Phase 4] Unauthenticated/Cross-Tenant `ModelHandler` Mutations (`internal/handlers/model.go`)**
   - *Impact:* Any user with `model:update`/`delete` in their own org could edit pricing/capabilities or delete models belonging to other tenants or global system providers.
   - *Remediation (Applied):* Enforced `authorizeProvider` (`UserID == caller` for writes, `403` on system provider writes, `404` on foreign providers) + `/api/models` user/system filtering. *Verified by automated tests.*
4. **[P0 — Fixed in Phase 4] Plaintext MCP Upstream Secret Header Leak (`internal/handlers/mcp.go:65-94`)**
   - *Impact:* `GET /api/mcp/servers/:id` decrypted `HeadersEncrypted` and returned bearer tokens & API keys in cleartext.
   - *Remediation (Applied):* Masked sensitive headers in `toEdit` and preserved untouched masked values during `PUT` (`buildMergedConfigHeaders`). *Verified by automated unit test.*
5. **[P0 — Fixed in Phase 4] Feature Flag `plan_tier` Spoofing (`internal/handlers/features.go:33-37`)**
   - *Remediation (Applied):* Removed `c.DefaultQuery("plan_tier", "free")`; always defaults to `"free"` unless middleware sets `"plan_tier"`. *Verified by unit test (`TestFeaturesHandler_IgnoresPlanTierQuerySpoofing`); live Docker container check not run while Docker daemon is offline.*
6. **[P0 — Open] Systemic Single-User (`user_id`) Scoping vs Multi-Member Organization Scoping (`repository/{agent,budget,mcp_server,governance_policy,routing_rule,provider}.go`)**
   - *Repro:* Team Member B in Organization X creates/views agents, budgets, or routing rules created by Owner A -> invisible to B because SQL queries `WHERE user_id = $1`, and `router.go:374` passes `gatewayKey.UserID` instead of `orgID`. Additionally, PostgreSQL RLS (`migrations/070`, `085`) fails open when `app.current_user_id` is unset (always unset by Go API).
   - *Remediation:* Standardize repositories on `org_id` + optional `workspace_id`/`project_id`, enforce session GUC `SET LOCAL` inside tx, and scope `CountActiveByProviderID` by owner/org.
7. **[P0 — Open] `/api/user/permissions` Lacks `TenantMiddleware` & Permission Context Hardcoding (`cmd/server/main.go:350`, `apps/app/contexts/PermissionProvider.tsx`)**
   - *Repro:* Switching orgs in `TenantSelector` fetches permissions for primary org only; frontend `PermissionProvider` grants owner fallback and is unused on pages (`routes` enforced backend-side only).
8. **[P1 — Open] `SafeHTTPTransport` Redirect Header Leakage Risk (`internal/proxy/engine.go`, `internal/security/ssrf.go`)**
   - *Impact:* While private IPs are blocked on connect/dial and `tool_gateway` uses `NewSafeHTTPClient`, default Go HTTP client redirect policy on custom provider URLs could forward `Authorization` / `x-api-key` if an upstream issues a 30x redirect to another public host. Add explicit `CheckRedirect` stripping sensitive headers across domains.

### Area B — Gateway Lifecycle & Reliability
1. **[P0 — Fixed in Phase 4] Redis Fail-Open Controls (`ratelimit.go`, `idempotency.go`, `auth.go`)** — Now fail-closed with `503` when `REDIS_FAIL_CLOSED=true` (production default). *Verified by automated tests.*
2. **[P1 — Open] Mid-Stream Client Disconnect Caches Truncated 200 OK Idempotent Replay (`internal/proxy/engine.go:1182-1228`, `handlers/gateway.go:300-302`)**
   - *Evidence:* `streamInterrupted` stays `false` when `scanErr != nil && ctx.Err() != nil` after tokens began flowing, so `SaveIdempotencyResult` saves a partial stream for 24h replay.
3. **[P1 — Open] Pre-First-Byte SSE Keepalive Sends Premature Failover Headers (`internal/proxy/sse_stream.go:73-107`)**
   - *Evidence:* After 15s waiting for headers, `pingWhileWaiting` flushes HTTP `200` + `X-Prism-Model: route0`; if `route0` fails and `engine` fails over to `route1`, headers mismatch the actual serving model.
4. **[P1 — Open] Provider Adapters Broken for Non-OpenAI Payloads (`proxy/{google,anthropic,openai_responses,opencode}.go`)**
   - *Evidence:* `SanitizeMessagesForGoogle` (`engine.go:511, 875`, `openai.go:18`) injects `thought_signature` globally; `google.go:38-40` rewrites `gemini-2.0-flash` to non-existent `gemini-3.6-flash`; `anthropic.go` omits `max_tokens` default, fails multi-turn `role: "tool"` & streaming `tool_use` delta parsing; `openai_responses.go` drops tools/temperature/tokens and mis-parses `"delta"` SSE events. `temperature: 0` dropped everywhere because `Temperature` is `float64`.

### Area C — Financial & Audit Integrity
1. **[P0 — Partially Fixed in Phase 4] Concurrent Budget Admission & Quota Enforcement (`budget_manager.go`, `admission.go`, `quota.go`, `orchestrator.go`)**
   - *Fixed:* Org/Workspace/Project quotas + daily request limits enforced; quota & budget DB errors fail closed; single-replica atomic `BudgetManager.Reserve`/`Release` prevents concurrent races; `Agent.MaxBudgetCents` enforced via `RequestLogRepository.GetAgentTotalSpendUSD`.
   - *Open (P1):* Distributed multi-replica reservation (Redis Lua), `MaxConcurrentStreams` enforcement (`tenant_quotas`), budgets scoped to `workspace_id`/`project_id`.
2. **[P0/P1 — Open] Async Audit/Log Non-Durability & Surrogate Hashing (`service/post_processor.go:95-231`, `proxy/side_effects.go:81-103`)**
   - *Impact:* Process crash drops in-memory post-processing writes (`request_logs`, `ai_audit_trails`); `post_processor.go:195-196` hashes metadata instead of real prompt/response bodies; failed requests in `gateway.go:382-398` omit `OrgID`, `WorkspaceID`, `ProjectID`, `AgentID`.
3. **[P1 — Open] Streaming `TTFTMs` Dropped on DB Persist & Prometheus `org_id="unknown"` (`proxy/engine.go:738-742, 1276-1298`)**
   - *Impact:* `GetLogAnalytics` `avgTtftMs` is always `0` for streamed requests; engine emits Prometheus `org_id` metric before `orchestrator` assigns `log.OrgID`.

### Area D — Async Processing & Resilience
- **Queue (`internal/queue/job_queue.go`) & Workers (`internal/workers/worker.go`):** Redis-backed async job queue supports worker leases and graceful drain via `jobQueue.Stop(ctx)` (`cmd/server/main.go:196`). However, **`workerStop()` does not wait for background workers (`anomaly`, `budget_alerts`, `latency`, `retention`, `credential_recovery`) to finish** (`workers/worker.go` has no `WaitGroup`), and Redis failure during `post_processor` shutdown cannot persist failed financial events to a durable DLQ.

### Area E — Smart Router Integrity
- **Fixed in Phase 4:** `X-Routing-Policy` now works on `/v1/chat/completions` & `/async` (`gateway.go:233`), and `ResolveSemantic` filters candidates via `CheckAgentResolvedModel` (`router.go:416`), preventing agents from bypassing `AllowedModels` via `prism-auto`.
- **Open Gaps (P1):** Keyword-only classifier (`classifier.go:95-492`) misclassifies short complex prompts as low complexity and URLs `.html`/`.php` as coding; no offline replay/benchmark framework; `/api/routing/simulate` diverges from live routing and returns wrong DTO field names for UI.

### Area F — Agent Governance & MCP
- **Fixed in Phase 4:** Inbound JSON-RPC 2.0 Streamable HTTP MCP server (`POST /v1/mcp`, `handlers/mcp_server.go`) exposing `tools/list` (filtered per agent) + `tools/call` for upstream `<server>__<tool>` and built-in `delegate_ai_task` (with explicit model/cost disclosure & budget enforcement); `ToolGatewayHandler` & `ResourceGatewayHandler` now enforce `AdmissionController`, `!deny` rules, and `AuditRecorder`.
- **Open Gaps (P0/P1):**
  - **Opt-in Agent Identity (`middleware/agent_policy.go:41-43`)**: Gateway keys still lack mandatory `agent_id` binding, so a caller omitting `X-Prism-Agent-ID` runs without agent constraints (`agent == nil`), and `X-Paperclip-Agent-ID` (`paperclip_handler.go:71-82`) sets `agentID` string after `AgentPolicyMiddleware` already skipped lookup.
  - **Zero Approval Workflows:** No `require_approval` effect, queue table, or approval API.
  - **Broken `rbac_engine.go:37` Substring Matching & Synthetic `mcp_server_invocations` (`engine.go:72-95`):** `strings.Contains` lets `"gpt-4"` match `"gpt-4o-mini"`, and `engine.go` writes synthetic `StatusCode: 200` MCP rows on chat completion tool-call JSON without executing the tool.

### Area G — Frontend Product Integrity (`apps/app`)
Confirmed by code inspection & frontend subagent audit:
1. Missing `eslint` binary (`pnpm --filter prism-dashboard lint` fails `spawn ENOENT`); Node 26 breaks `client.test.ts` on `localStorage`; **zero E2E Playwright tests**.

3. `Playground` (`playground/page.tsx`) duplicates `prism-auto`, ignores selected model, and mismatches `/api/routing/simulate` field names (displaying `0` scores/cost).

5. `ResourceFormDialog` hardcodes `backends: []`; `MCPServerForm` leaves `transportType: "http"` when switching to `"local"`; `AgentFormDialog` omits `AllowedModels`/`SystemPromptOverride`/`Enabled`; `ProviderFormDialog` lacks close-on-success handling.
6. `Logs` hardcodes 10-row fetch; `Models` hardcodes fake `92%`/`95%` fallback scores; `/analytics/finops/*`, `/routing-rules`, `/routing/decisions`, and `/agent-templates` lack UI management pages.
